# Git Journal

## What I Learned
I learned how to actually use Git in a full workflow by creating branches, making commits, pushing to GitHub, and fixing mistakes along the way.  
It made me realize how developers manage changes and teamwork in real projects.

## Mistakes I Fixed
1. I messed up a merge conflict but fixed it by carefully editing and saving only what I needed.  
2. I used the wrong command once but figured it out by checking my branch and redoing it the right way.

## Command or Feature That Saved the Day
Definitely **git branch** and **git checkout** as they helped me move between branches without breaking things and kept everything organized.
