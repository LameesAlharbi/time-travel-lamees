# Time-Travel Zine
I’m learning Git while making a small zine about time travel.

## Branch Roles
- `author/idea-sprint`: where I brainstorm and write my ideas.
- `editor/review`: where I fix and polish everything before finalizing.

## Why .gitignore patterns matter
Some files don’t need to be shared, like:
- `.DS_Store`: mac stuff that’s automatically created.
- `target/`: build files we don’t really need in Git.
